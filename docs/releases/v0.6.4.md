# UnlockTime v0.6.4 · build17

**适配范围：目前仅完整适配 Samsung Galaxy S24+（SM-S9260 / Android 16 / 图案锁屏）。其他机型未适配。**

本次发布已在手机验证的 0.6.4 / build17 Debug APK。相较仓库原 0.5.0：

- 新增本地 `repeat_tap`：固定坐标或矩形中的固定位置，最多 60 次，可设置间隔；整个序列只调用一次模型工具，按真实手势完成回调计数。
- 默认普通应用内页面变化继续原位置点击，可明确选择换页停止；保留停止任务、锁屏、受保护捕获和风险确认。
- 修复完整任务中的“不要设置 stop_on_page_change=true”被误判为不执行、返回 `NOT RUN`。
- 移除原 1000 字任务提示词限制，保留完整任务文本。
- 保留本地自动解锁、单一无障碍服务、应用序列和原数据格式；吸收 OpenPhoneUse v0.0.8 的屏幕截取保护修复。没有宣称完全跟随上游 main。

验证：真实微信完整任务一次 60/60；S24+ 自动解锁并打开计算器三轮 3/3；JVM 1695 通过、3 跳过、0 失败，Lint 0 错误/106 警告。原签名和任务数据保留。

连点试验前目标已处于使用中，不能算新预约成功。三轮解锁不是整夜待机验证。任务重叠会等待，但多个积压任务尚未强制按计划时间排序，超过各自计划时间 10 分钟会跳过本次。

下载安装 `UnlockTime-v0.6.4-build17-debug.apk`。已安装同签名版本可覆盖更新；不要卸载或清除数据。自编译可能签名不同。公开源码样例已脱敏，原账号、凭据、私钥和手机截图不在发布包内。
